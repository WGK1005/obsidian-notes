1.**为什么学习卡尔曼滤波要掌握逆矩阵？**

因为卡尔曼增益公式中存在：
K = PHT (H PHT + R)−1
你暂时不用理解整个公式，但必须知道：
- 矩阵乘法负责组合不同状态之间的关系。
- 转置用于构造相关的矩阵运算。
- 逆矩阵用于求解观测更新中的线性系统。

实际编程时，通常不会直接计算矩阵逆，而是使用线性方程求解方法，提高数值稳定性。
2.**协方差：卡尔曼滤波最重要的基础**
前面我们描述了机器人在哪里。

但还有一个问题：

**我们有多大把握认为机器人真的在那里？**

假设两个传感器都报告：

\[ x=5m \]

但是它们的测量质量不同。

- 传感器 A：误差通常在很小范围内。
    
- 传感器 B：测量结果经常波动。
    

虽然它们测量结果相同，但我们显然更相信 A。

这就是不确定性。

### **1. 方差**

假设有一组位置测量数据：

\[ X=[4,5,6] \]

平均值：


方差（这里使用总体方差）：

\[ \sigma^2=\frac{(4-5)^2+(5-5)^2+(6-5)^2}{3} \]

\[ \boxed{\sigma^2=\frac23} \]

方差越大，数据波动越大。

方差越小，数据越集中。

> [!tip] 注意
> 协方差描述的是统计意义上的不确定性，不是机器人真实位置误差的直接测量值。

```python

import numpy as np

# 1. 定义机器人状态
X = np.array([
    [3],
    [4],
    [2],
    [1]
])

print("机器人状态：")
print(X)

# 2. 状态转移矩阵
dt = 1.0

F = np.array([
    [1, 0, dt, 0],
    [0, 1, 0, dt],
    [0, 0, 1, 0],
    [0, 0, 0, 1]
])

# 3. 预测下一时刻状态
X_next = F @ X

print("\n下一时刻状态：")
print(X_next)

# 4. 矩阵转置
print("\nF的转置：")
print(F.T)

# 5. 协方差矩阵
P = np.diag([4, 4, 1, 1])

print("\n协方差矩阵：")
print(P)

# 6. 预测协方差
Q = np.eye(4) * 0.1

P_next = F @ P @ F.T + Q

print("\n预测后的协方差：")
print(P_next)

# 7. 矩阵求逆
A = np.array([
    [2, 0],
    [0, 4]
])

print("\n矩阵逆：")
print(np.linalg.inv(A))

```
