# 高程图、可行性分析与地形数据集

> 收录 2.5D 高程建图、网格地图底座、几何/学习型可通行性评估、空洞补全以及足式机器人基准数据集。

---

## 一、 核心高程建图与数据结构（Elevation Mapping & Grid Map）

### 1. elevation_mapping_cupy（GPU 加速版 ⭐核心）
- **项目地址**：https://github.com/leggedrobotics/elevation_mapping_cupy
- **核心作用**：ETH Zurich RSL 开源的 **GPU 加速（CuPy/CUDA）** 机器人中心局部高程建图框架。支持点云/深度图实时融合、基于光线投射（Raycasting）的动态障碍物清理、语义层融合以及自定义地形滤波插件（坡度、台阶、粗糙度、方向可行性等），**最适合 Unitree Go2 等足式机器人及后续接入强化学习/仿真**。

### 2. elevation_mapping_ros2（CPU ROS 2 版）
- **项目地址**：https://github.com/norlabulaval/elevation_mapping_ros2
- **核心作用**：ETH 经典 CPU 版 `elevation_mapping` 的 ROS 2 移植维护版（NorLab）。以机器人里程计与协方差融合构建局部 2.5D 高程图，适合无独立 GPU 的边缘端部署参考或与 CuPy 版本做架构/效果对比。

### 3. grid_map
- **项目地址**：https://github.com/ANYbotics/grid_map
- **核心作用**：ANYbotics 开源的通用多图层 2.5D 网格地图 C++ 核心库。支持在同一张移动网格地图中叠加高程、方差、法向量、坡度、通行代价等多种图层，并提供 RViz 可视化插件与 ROS 消息/OpenCV/Eigen 转换接口，是各类高程图与可行性分析系统的底层基础设施。

## 二、 地形可行性分析（Traversability Estimation）

### 4. traversability_estimation（ETH 经典几何法 ⭐核心参考）
- **项目地址**：https://github.com/leggedrobotics/traversability_estimation
- **核心作用**：ETH RSL 开源的经典几何地形可通行性评估框架。直接基于高程图提取**坡度（Slope）、台阶高度（Step）、粗糙度（Roughness）**三项几何特征，通过加权融合输出全局/局部通行代价图，是足式机器人可行性分析最标准的工程范式。

### 5. traversability_mapping（BGK 概率推断法）
- **项目地址**：https://github.com/TixiaoShan/traversability_mapping
- **核心作用**：山提晓（LIO-SAM 作者）开源的基于**贝叶斯广义核推断（BGK）**的局部高程建图与可通行性评估系统。在激光点云较稀疏的远距离或边缘区域，能够利用核推断平滑地预测地形高度并给出通行性估计。

### 6. traversability_estimation（CNN 学习型）
- **项目地址**：https://github.com/romarcg/traversability_estimation
- **核心作用**：基于卷积神经网络（CNN）的越野地形可行性预测开源项目。直接将高程图切片输入 CNN 预测不同构型机器人（轮式、履带、足式）在非结构化地形上的通过成功率与代价，适合从“纯几何判据”向“数据驱动/学习型判据”进阶时参考。

## 三、 高程图补全与不确定度估计（Map Completion）

### 7. elevation-map-completion
- **项目地址**：https://github.com/michKovac/elevation-map-completion
- **核心作用**：结合深度学习（U-Net）与传感器几何感知掩码（Ray-cone masking）的高程图空洞补全项目。针对雷达安装高度与自遮挡/盲区导致的近身或台阶背面空洞进行物理合理性补全，并同步输出每个栅格的预测不确定度，防止规划器盲目踩坑。

## 四、 基准数据集（Benchmark Dataset）

### 8. GrandTour Dataset（ETH 足式机器人数据集）
- **项目地址**：https://grandtour.leggedrobotics.com/dataset#mission-22-on
- **核心作用**：ETH RSL 发布的大规模、多模态野外及复杂地形足式机器人数据集（由 ANYmal 搭载 Boxi 多传感器套件采集）。涵盖楼梯、碎石、森林、雪地、昼夜交替等丰富场景，包含高精度真值位姿、多线雷达与深度相机数据，是离线验证高程图建图与可行性分析效果的黄金基准。
