# 路径规划、轨迹优化与导航框架

> 收录非完整约束前端搜索（Hybrid A*）、ESDF 后端优化以及 ROS 2 / 竞赛级完整导航栈。

---

## 一、 完整导航系统与定位模块（Navigation Stack）

### 1. SCURM_SentryNavigation（竞赛级轻量化导航栈）
- **项目地址**：https://github.com/PolarisXQ/SCURM_SentryNavigation
- **核心作用**：川大火锅战队（SCURM）开源的 RoboMaster 哨兵机器人完整导航与定位方案。亮点在于将 FAST-LIO2 改造为低 CPU 占用的定位模式（无需额外重量级重定位节点），并对 Nav2 插件、行为树及碰撞脱困恢复机制进行了实战优化，工程落地参考价值极高。

### 2. nav2_amcl（ROS 2 官方定位节点）
- **项目地址**：https://github.com/ros-navigation/navigation2/tree/humble/nav2_amcl
- **核心作用**：ROS 2 Humble 官方 Nav2 导航框架中的自适应蒙特卡洛定位（AMCL）核心源码。基于粒子滤波在 2D 占据栅格地图中实现激光定位，是学习 Nav2 生命周期管理、TF 树规范及 2D 导航对接的标准参考。

---

## 二、 前端搜索与后端轨迹优化（Path Planning & Optimization）

### 3. Hybrid-Astar-ESDF
- **项目地址**：https://github.com/Orangefruit777/Hybrid-Astar-ESDF
- **核心作用**：结合 **Hybrid A\*** 前端搜索与 **ESDF（欧氏符号距离场）** 的路径规划与轨迹优化项目。前端保证运动学可行性，后端利用 ESDF 提供的距离与梯度信息进行避障平滑优化，输出光滑、安全且贴合机器人动力学约束的轨迹。

### 4. Hybrid_A_Star
- **项目地址**：https://github.com/zm0612/Hybrid_A_Star
- **核心作用**：结构清晰、注释友好的 C++ 版 **Hybrid A\*** 经典算法实现。完整包含栅格离散化状态扩展、碰撞检测与 Reeds-Shepp 曲线解析扩展，非常适合用于算法原理学习以及在此基础上魔改足式/移动机器人的前端搜索模块。
